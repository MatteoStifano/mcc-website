# Monopoli Coders Club — sito web

Sito della community di sviluppatori, studenti e appassionati di tecnologia di Monopoli: **[www.monopoli-coders-club.com](https://www.monopoli-coders-club.com)**

- Homepage in italiano (`/`) e inglese (`/en/`) con prossimo evento, workshop, blog, progetti e contatti
- Blog scritto dai membri, in Markdown
- Generato con [Astro](https://astro.build/) e pubblicato gratuitamente su GitHub Pages tramite GitHub Actions

## Contribuire

- **Hai organizzato un evento?** Aggiungilo in [`src/data/events.json`](src/data/events.json).
- **Vuoi scrivere un articolo?** Aggiungi un file Markdown in [`src/content/blog/`](src/content/blog/).
- **Vuoi tenere un talk?** Usa il modulo [Proponi un talk](https://github.com/MatteoStifano/mcc-website/issues/new?template=proposta-talk.yml).
- **Vuoi migliorare il sito?** Apri una issue o una pull request.

I dettagli sono in [CONTRIBUTING.md](CONTRIBUTING.md).
